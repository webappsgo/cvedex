# Translating cvedex

The current web pages and API messages are English-only, and this release has
no translation catalog or translation workflow. Do not add ad hoc translated
strings. When localization support is enabled, translators should use the
project's message catalog, keep one source-language entry per message, and
submit translations for review with the source message and target locale
identified.

Preserve CVE identifiers, DNS names, API field names, CVSS vectors, and
upstream source names exactly. Translate user-facing prose, but leave protocol
values and machine-readable output unchanged. Review translations for
terminology consistency, accessibility, and text expansion before release;
credit translators by their preferred name only with their consent.
