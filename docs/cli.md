# Command line client

`cvedex-cli` provides one-shot commands for automation and starts an interactive
terminal interface when run without a command in an interactive terminal. The
client is read-only against server data; `data generate` and `data sync` are
local dataset maintenance tools.

## Configuration

The client creates `cli.yml` under the current user's configuration directory:

- Unix: `~/.config/casapps/cvedex/cli.yml`
- Windows: `%APPDATA%\casapps\cvedex\cli.yml`

Configuration files are created with owner-only permissions on Unix. Use
`--config PATH` or `--config PROFILE` to select another file or profile. The
server can be set with `--server`, `CVEDEX_SERVER_PRIMARY`, or
`server.primary` in `cli.yml`. Set `server.cluster` to ordered fallback URLs;
the client refreshes this list from the server health response at most every
30 minutes. The shared request user agent is `cvedex-cli/{version}`.
The client checks autodiscovery on each configured-server invocation. A newer
version prompts in an interactive terminal. Non-interactive updates are
installed only when `update.auto: true` is set. Use `--update check` to inspect
an update or `--update yes` to install it immediately.

Tokens can be supplied with `--token`, `--token-file`, `CVEDEX_TOKEN`, or the
`auth.token` and `auth.token_file` config entries. Token files must be regular
files with mode 0600 or stricter on Unix. Public CVE data does not require a
token.

## Interactive terminal interface

Run `cvedex-cli` in an interactive terminal. Enter a CVE ID to open its record,
or enter search terms to search the index. Press `Enter` to submit, `?` for
help, and `q` or `Ctrl+C` to quit. `tui.enabled` controls whether the TUI is
available; `tui.theme` selects `dark` or `light`. Layout adapts to terminal
size using the shared terminal size modes and ANSI theme palette.

## Commands

```sh
cvedex-cli get CVE-2024-3094
cvedex-cli latest --limit 20
cvedex-cli search "xz utils" --year 2024 --severity critical --kev true
cvedex-cli vendors --limit 50
cvedex-cli vendor Acme
cvedex-cli vendor-products Acme
cvedex-cli products
cvedex-cli product Widget
cvedex-cli kev
cvedex-cli ds
cvedex-cli health
cvedex-cli autodiscover
cvedex-cli zone generate --output ./cve.zone
```

Search supports `--year`, `--severity`, `--kev`, `--limit`, and `--cursor`.
Catalog listing commands accept `--limit` and `--cursor`. The `--server` flag
can be used with any API command.

Output formats are `table` (default), `plain`, `json`, `yaml`, and `csv`:

```sh
cvedex-cli get CVE-2024-3094 --output json
cvedex-cli search xz --output csv
```

## Data generation and synchronization

`data generate` builds the compressed dataset from a local cvelistV5 checkout
and the official KEV and EPSS feeds. `data sync` downloads and verifies a
published dataset and checksum.

```sh
ARTIFACT_DIR=$(mktemp -d "${TMPDIR:-/tmp}/cvedex-XXXXXX")
cvedex-cli data generate --source-dir ./cvelistV5 --output "$ARTIFACT_DIR/cvedex-data.json.gz"
cvedex-cli data sync --data-url https://example.invalid/cvedex-data.json.gz \
  --checksum-url https://example.invalid/cvedex-data.json.gz.sha256 \
  --output "$ARTIFACT_DIR/cvedex-data.json.gz"
```

Generated files belong in a temporary artifact directory rather than the
source tree. `data generate` accepts `--kev-url` and `--epss-url` overrides.

## Shell completion

Completions are generated by the binary, so no external completion file needs
to be kept in sync. Supported shells are bash, zsh, fish, sh, dash, ksh,
powershell, and pwsh. If omitted, the shell is detected from `$SHELL` and falls
back to bash.

```sh
cvedex-cli --shell completions bash > ~/.local/share/bash-completion/completions/cvedex-cli
eval "$(cvedex-cli --shell init bash)"
cvedex-cli --shell completions powershell > ~/cvedex-cli.ps1
```

`--shell init [SHELL]` prints the command to load completions in the current
shell. `--shell --help` prints the supported shell usage.

For `ksh`, generated output uses its `compctl` word list. POSIX `sh` and `dash`
do not define a programmable completion interface; generated output defines
`cvedex_cli_complete PREFIX`, which prints matching command names for a shell
line editor or wrapper to consume. Source the output with `eval "$(cvedex-cli
--shell completions sh)"` before calling that helper.
